How the systems built with the `AgenticServices` builders are found, in dev mode. `cdi`: the beans the application produces whose type is an agent (`UntypedAgent`, `SupervisorAgent`) or whose producer calls a builder's `build()`; they are created when the Dev UI first lists the systems, not at startup.
